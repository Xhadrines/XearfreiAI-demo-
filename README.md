# XearfreiAI-demo-

XearfreiAI-demo is a desktop Python application functioning as a chat with a Llama 3.1 language model. Features include text-to-speech (TTS) and speech-to-text (STT), optional internet search (Wikipedia and Google), and interactive commands such as updating the application code. Users can activate/deactivate features via the options menu. The project demonstrates early experimentation with AI chat applications and automated code modifications.
